# Stream Emotes

A Fabric mod that brings [Twitch](https://twitch.tv)'s emotes to Minecraft! (Even the animated ones)

Features:

* You can use all the emotes of all the streamers you're subscribed to on Twitch
* You will see other people's emotes if they are subscribed to that streamer's emotes

## Installation

* Download the mod from the [Releases Page](https://github.com/azertyfun/StreamEmotes/releases)
* Install Fabric and the Fabric API
* Put the mod in your mods folder
* Link your Twitch account to your minecraft username on [stream-emotes.e4b4.eu](https://stream-emotes.e4b4.eu/)
* Profit!
